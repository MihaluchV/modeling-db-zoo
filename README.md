# modeling-db-zoo
# 🦁 Замовлення бази даних для зоопарку

Інтерактивне завдання з інформатики для 9 класу на тему «Бази даних. Побудова моделі БД».
Учні виконують роль розробників: створюють таблиці, розподіляють поля, обирають типи даних
і встановлюють зв'язки між таблицями.

## Рівні складності
| Рівень | Бали | Етапи |
|---|---|---|
| Базовий | 8 | готові таблиці з ключами → поля → типи → зв'язки (тип зв'язку автоматично) |
| Достатній | 10 | 4 порожні заготовки → назви → поля (є зайві) → типи → зв'язки |
| Поглиблений | 12 | усе самостійно, більше зайвих полів, вибір типу зв'язків + додаткове завдання про годування |

## Можливості
- введення прізвища, імені та класу на початку;
- автоперевірка на кожному етапі та підрахунок помилок;
- підсумок-картка PNG зі схемою БД і переліком допущених помилок;
- відправлення результату поштою (`mailto:`) з готовим текстом листа.
